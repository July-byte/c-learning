# Event Handling Demo (Delegates & Lambda)
Консольное приложение на C#, демонстрирующее механизм обработки событий с использованием делегатов и лямбда-выражений.
Проект разработан в рамках практического задания по закреплению знаний о делегатах, событиях и функциональных возможностях языка C#.

---

## Цель работы
Реализовать механизм генерации и обработки событий с использованием:
* делегатов
* встроенного механизма event
* лямбда-выражений
* подписки и отписки обработчиков

---

## Задачи проекта
* Создать класс-издатель (Publisher), генерирующий события
* Реализовать передачу данных через EventArgs
* Организовать подписку нескольких обработчиков на одно событие
* Реализовать обработчики через лямбда-выражения
* Продемонстрировать процесс отписки
* Показать работу замыканий
* Реализовать базовое логирование
* Обеспечить разделение логики генерации и обработки событий

---

## Используемые технологии
* C#
* .NET 8
* Делегаты
* События (event)
* EventHandler<T>
* Лямбда-выражения
* Принципы ООП
* Базовое логирование

  ---

## Реализованный функционал
* Генерация пользовательского события
* Подключение нескольких подписчиков
* Обработка события через анонимные лямбда-методы
* Поддержка подписки и отписки
* Передача параметров события
* Демонстрация замыкания
* Разделение ответственности между классами

---

## Результаты работы
В ходе выполнения задания были закреплены знания:
* механизма делегатов в C#
* внутренней модели событий
* принципа "издатель-подписчик"
* использование обобщенных делегатов (EventHandler<T>)
* проектирования расширяемого механизма обработки событий

Проект демонстрирует понимание событийной модели .NET и принципов слабой связанности компонентов.
