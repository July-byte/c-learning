# Data Processor (LINQ + File I/O)
Консольное приложение на C#, предназначенное для чтения данных из CSV-файла, их фильтрации и сортировки с использованием LINQ и последующей записи обработанных данных в новый файл.
Проект выполнен в рамках практического занятия по закреплению работы с файлами и LINQ.

---

## Цель проекта
Разработать приложение, которое:
* считывает структурированные данные из CSV-файла
* предоставляет пользователю возможность фильтрации и сортировки данных
* записывает обработанный результат в новый файл

---

## Реализованный функционал
* поддержка чтения CSV-файла
* проверка существования файла
* парсинг строк в объекты модели
* обработка ошибок формата и чтения
* поддержка кодировки UTF-8

---

## Фильтрация (LINQ)
Пользователь может фильтровать данные по:
- возрасту
- категории (contains)
- зарплате
- дате регистрации

Используются методы LINQ:
- 'Where"
- 'ToList'
- 'Any'

Обрабатывается ситуация отсутствия результатов.

---

## Сортировка (LINQ)
Поддерживается сортировка по:
- имени
- возрасту
- зарплате
- дате регистрации

Возможен выбор порядка:
- по возрастанию
- по убыванию

Используются:
- 'OrderBy'
- 'OrderByDescending'

---

## Запись в файл
- Сохранение результатов в новый CSV-файл
- Выбор пути пользователем
- Перезапись файла
- Обработка ошибок записи

---

## Используемые технологии
- C#

- StreamReader / StreamWriter

- Обработка исключений
